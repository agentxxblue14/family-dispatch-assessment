## One request in full

Logged in as owner@alpha.test, asking for a Beta Logistics load by its id. The curl line is the equivalent command; the response under it is exactly what the server sent the script:

```
curl -i -b "fd.sid=<session cookie from login>" http://localhost:3000/api/loads/5

HTTP/1.1 404 Not Found
Content-Type: application/json; charset=utf-8

{"error":"Not found"}
```

The answer is the same as for a load id that does not exist at all, so the caller cannot even learn that
the record exists.
